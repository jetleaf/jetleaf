### Slide 2: The Architectural Problem / Anti-Pattern
* **Headline:** The "Hallucination Loop" of Dynamic Backends
* **The Struggle:**
  When prompting AI agents (Cursor, Windsurf, Claude Desktop) to build Node.js or Python backends:
  * Routes get registered in 4 disconnected files (missing router imports, dangling middleware).
  * Payloads drift: Runtime JSON lacks compile-time validation, causing silent 500 crashes.
  * Context explosion: The LLM has to re-read the entire repository just to know if a database connection service exists.
* **Result:** You spend 80% of your time fixing AI "syntax drift" and debugging runtime crashes in loosely-typed frameworks.

---

### Slide 3: The Jetleaf Way — Deterministic AI Architecture
* **Headline:** Declarative Contracts + Model Context Protocol
* **The Solution:**
  Jetleaf's strict IoC Pod registry and declarative annotations give AI agents an unambiguous AST. Connect `jetleaf_mcp` to your IDE agent: the agent scaffolds complete, validated endpoints in a single prompt without missing route registrations.

```dart
// Generated by Claude Desktop via jetleaf_mcp
@RestController()
@RequestMapping('/api/v1/auth')
class AuthController {
  final AuthService _authService;

  // Jetleaf IoC injects the Pod automatically via constructor
  AuthController(this._authService);

  @PostMapping('/register')
  Future<ResponseEntity<UserResponseDto>> register(
    @Valid() @RequestBody() RegisterRequestDto request,
  ) async {
    final user = await _authService.registerUser(request);
    return ResponseEntity.created(user);
  }
}
```

### Slide 4: Deep Dive — How `jetleaf_mcp` Works Under the Hood
* **Headline:** Bridging LLM Reasoning with the JetleafVM Engine
* **Architecture Flow:**
  1. **MCP Tools Exposure:** `jetleaf_mcp` runs a local Model Context Protocol server exposing tools: `inspect_pods`, `get_routes`, `run_tests`, and `scaffold_feature`.
  2. **AST-Level Awareness:** Instead of blindly reading text files, the LLM queries the Jetleaf AST scanner. It knows every active `@Pod`, `@Configuration`, and `@RestController` instantly.
  3. **Zero Routing Boilerplate:** Because Jetleaf uses Spring-style annotation discovery, the AI agent doesn't need to manually edit `server.dart` or route tables. It drops a `@RestController` file into `/src/controllers/`, and the resident daemon hot-reloads it in **< 90ms**.

### Slide 5: Enterprise Pro-Tip — The Autonomous Self-Healing Loop
* **Headline:** Closed-Loop Autonomous Test Healing
* **Pro-Tip:**
  Configure your IDE AI rule to utilize `jetleaf_mcp` with `jl test` inside pre-warmed isolates:
  
```bash
# Agent runs verification over JetleafVM daemon
jl test --filter="AuthControllerTest"
```

* **The Self-Correction Workflow:**
  * If a `@Valid` validation constraint fails in a test (e.g., `@Email` or `@Size(min: 8)`), `jetleaf_mcp` intercepts the exact Isolate stack trace.
  * The agent reads the typed DTO error, adjusts the constraint validator in the DTO, and re-triggers tests against the pre-warmed VM without cold-booting Dart.
  * **Zero human intervention required** to get from prompt to green test suite.

## Ready-to-Copy Social Caption

Vibecoding backend APIs with LLMs usually starts fast… until runtime chaos hits. 💥

In loosely-typed frameworks (Node/Express, Flask), AI agents routinely:
❌ Forget to register routes in manual pipeline chains
❌ Hallucinate imports that don’t exist
❌ Emit DTOs that crash silently at runtime due to loose typing

With **Jetleaf** + **Model Context Protocol (`jetleaf_mcp`)**, Dart backend development becomes deterministic for AI agents. 🎯

Because Jetleaf uses an enterprise Inversion of Control (IoC) engine with declarative annotations:
1. **The LLM never edits route tables:** An agent simply scaffolds an `@RestController` with `@PostMapping`, and Jetleaf discovers it automatically.
2. **Deterministic Schemas:** `@Valid` and typed DTOs ensure the agent's generated code adheres strictly to type contracts.
3. **AST Introspection:** Through `jetleaf_mcp`, agents (Cursor, Windsurf, Claude Desktop) inspect your live IoC Pod container directly via JSON-RPC.
4. **Autonomous Self-Healing:** The agent triggers `jl test` on the resident warm `JetleafVM` daemon, captures stack traces, and self-heals failing assertions in under 2 seconds.

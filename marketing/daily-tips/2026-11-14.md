### Slide 3: The Jetleaf Way — Clean Code Example
* **Header:** THE JETLEAF WAY
* **Headline:** Deterministic Code Scaffolding via `@Pod` & MCP
* **Code Card (Dart):**
  ```dart
  import 'package:jetleaf/jetleaf.dart';
  import 'package:jetleaf_web/jetleaf_web.dart';

  @RestController()
  @RequestMapping('/api/v1/agents')
  class AgentTaskController {
    final TaskExecutionService _taskService;

    // Autowired via IoC container: AI agent never writes manual instantiations
    AgentTaskController(this._taskService);

    @PostMapping('/run')
    Future<ResponseEntity<TaskResult>> executeTask(
      @Valid @RequestBody TaskPayload payload,
    ) async {
      final result = await _taskService.process(payload);
      return ResponseEntity.ok(result);
    }
  }
  ```
* **Callout:** `jetleaf_mcp` exposes explicit AST routes & typed Pod definitions directly to Cursor & Claude Desktop.

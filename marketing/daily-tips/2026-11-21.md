### Slide 2: The Architectural Problem
**Header Tag:** THE LLM CONTEXT GAP  
**Title:** Why AI Coding Breaks on Legacy Backends  

```
❌ Traditional LLM Backend Workflow:
 [ Prompt Agent ] ──> [ Generates Untyped Node/Python Code ]
                            │
                            ▼
     [ Runtime Runtime Error / Dynamic JSON Mismatch ]
                            │
                            ▼
 [ Dev Manually Copies Error Log Back into Prompt Window ] 🔁 Repeat endlessly...
```

* **Context Rot:** Generic AI prompts lack awareness of dynamic framework routes, IoC container graphs, and raw map payloads.
* **No Runtime Feedback Loop:** The LLM cannot test its own code or inspect the server AST while scaffolding.
* **Runtime Dynamic Failures:** Dynamic JSON structures lead to hidden `NoSuchMethodError` crashes in production.

### Slide 3: The Jetleaf Way (Code Example)
**Header Tag:** THE JETLEAF SOLUTION  
**Title:** Zero-Boilerplate MCP Integration  

```dart
// 1. Configure jetleaf_mcp in your server application context
import 'package:jetleaf/jetleaf.dart';
import 'package:jetleaf_mcp/jetleaf_mcp.dart';

@Configuration()
class McpAgentConfig {
  @Pod()
  McpServer mcpServer(PodRegistry registry) {
    return JetleafMcp.create(
      projectName: 'billing-service',
      enableAstInspection: true,
      enableWarmVmTesting: true,
      podRegistry: registry,
    );
  }
}

// 2. AI Agents (Cursor / Claude / Antigravity) gain live tools:
// - jl_mcp_inspect_routes : List all @RestController endpoints
// - jl_mcp_verify_pods    : Verify IoC Dependency Graph integrity
// - jl_mcp_run_tests      : Execute isolate-warm tests & capture stack traces
```

### Slide 4: Deep Dive — How `jetleaf_mcp` Works
**Header Tag:** UNDER THE HOOD  
**Title:** The Autonomous AI Self-Healing Loop  

```
 ┌─────────────────────────────────────────────────────────┐
 │                   Cursor / Claude Agent                 │
 └──────────────────────────┬──────────────────────────────┘
                            │ Model Context Protocol (MCP)
                            ▼
 ┌─────────────────────────────────────────────────────────┐
 │                  jetleaf_mcp Daemon                     │
 │  ┌───────────────────┬───────────────────────────────┐  │
 │  │   AST Inspector   │  Warm Isolate Test Driver     │  │
 │  └─────────┬─────────┴───────────────┬───────────────┘  │
 └────────────┼─────────────────────────┼──────────────────┘
              ▼                         ▼
   [ Route & Pod Graph ]    [ Sub-100ms Execution ]
              │                         │
              └──────────┬──────────────┘
                         ▼
       Zero-Hallucination Server Generation
```

1. **AST & Route Table Reflection:** Exposes `@RestController` structures and `@Pod` dependency graphs directly to the LLM via standardized JSON-RPC MCP tools.
2. **Warm Isolate Test Harness:** When the agent edits code, `jetleaf_mcp` executes sub-100ms tests in warm Dart isolates.
3. **Autonomous Self-Healing:** If an assertion fails, structured compiler errors and stack traces stream directly back into the agent prompt context for automatic resolution without human intervention.

### Slide 5: Pro-Tip — Vibecoding Best Practice
**Header Tag:** PRODUCTION BEST PRACTICE  
**Title:** Enforce Strict Types + `@Valid` Constraints  

```dart
// Combine DTO validation annotations with MCP for 100% first-pass AI generation accuracy
class CreateSubscriptionDto {
  @NotNull()
  @Email()
  final String customerEmail;

  @NotNull()
  @Min(1)
  final int tierId;

  CreateSubscriptionDto({
    required this.customerEmail,
    required this.tierId,
  });
}

// Pro-Tip: Add `@Valid` to your controller parameters.
// The MCP tool allows AI agents to infer exact request validation contracts
// and auto-generate client SDKs without API contract drift!
```

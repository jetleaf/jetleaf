### Slide 3: The Jetleaf Way — Clean Code Example
* **Header:** `THE JETLEAF WAY`
* **Title:** One Shared Dart DTO, Zero Drift
* **Code Example (Dart):**

```dart
// 1. SHARED MONOREPO PACKAGE: packages/api_contracts/lib/user_dto.dart
import 'package:jetson/jetson.dart';
import 'package:jetleaf_validation/jetleaf_validation.dart';

@JsonSerializable()
class CreateUserDto {
  @NotNull()
  @Email()
  final String email;

  @NotNull()
  @Size(min: 8, max: 64)
  final String password;

  const CreateUserDto({required this.email, required this.password});
  
  factory CreateUserDto.fromJson(Map<String, dynamic> json) => _$CreateUserDtoFromJson(json);
  Map<String, dynamic> toJson() => _$CreateUserDtoToJson(this);
}

// 2. JETLEAF BACKEND ROUTE: apps/backend/lib/user_controller.dart
@RestController('/api/v1/users')
class UserController {
  @PostMapping()
  Future<ResponseEntity<UserResponse>> createUser(
    @Valid() @RequestBody() CreateUserDto dto,
  ) async {
    // Typed DTO validated automatically before method entry!
    return ResponseEntity.created(await _userService.register(dto));
  }
}
```

### Slide 4: Deep Dive / How it Works Under the Hood
* **Header:** `UNDER THE HOOD`
* **Title:** End-to-End Type Safety Across Isolates
* **Bullet Points:**
  * **Shared Monorepo Architecture:** Flutter app and Jetleaf backend import the exact same Dart package (`packages/api_contracts`).
  * **Unified Validation & Serialization:** Jetson handles sub-millisecond JSON parsing while `@Valid` annotations enforce server-side security.
  * **Compile-Time Contract Guarantees:** Breaking changes in your API DTO instantly fail both client and backend builds (`dart analyze` catches everything).
  * **Zero Code Generation for HTTP Clients:** Consume response objects directly using shared typed models on Flutter without manual casting.

* **Architecture Structure:**
```text
my_fullstack_app/
├── apps/
│   ├── backend/      # Jetleaf framework app
│   └── mobile/       # Flutter iOS/Android app
└── packages/
    └── contracts/    # Shared DTOs, Enums, Validation rules
```
* **Best Practice:** Run `jl dev` in `apps/backend` alongside `flutter run` in `apps/mobile`. When you update a model in `packages/contracts`, both client and server hot-reload instantly with absolute type safety!

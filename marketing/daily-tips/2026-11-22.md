### Slide 3: The Jetleaf Way (Clean Code Example)
* **Header:** Clean, Declarative Resilience ✨
* **Subtext:** Wrap transient network operations with `@Retryable` and automatic backoff strategies.
* **Code Snippet:**

```dart
import 'package:jetleaf_core/jetleaf_core.dart';
import 'package:jetleaf_retry/jetleaf_retry.dart';

@Pod()
class PaymentGatewayService {
  final HttpClient _client;

  PaymentGatewayService(this._client);

  @Retryable(
    include: [TimeoutException, SocketException],
    maxAttempts: 3,
    backoff: Backoff(delayMs: 500, multiplier: 2.0),
  )
  Future<PaymentResult> processCharge(PaymentRequest request) async {
    // Jetleaf dynamically intercepts calls to this method
    return await _client.post('/charges', body: request.toJson());
  }

  @Recover
  Future<PaymentResult> fallbackCharge(SocketException e, PaymentRequest req) async {
    // Graceful degradation when retries are exhausted
    return PaymentResult.queuedForOfflineProcessing(req);
  }
}
```

---

### Slide 4: Deep Dive / How It Works Under the Hood
* **Header:** Under the Hood: IoC Interception ⚙️
* **Key Mechanics:**
  1. **Dynamic Proxy Wrapping:** When `jetleaf_core` initializes your `@Pod`, it wraps methods annotated with `@Retryable` in an AST-driven proxy interceptor.
  2. **Exception Filtering:** The framework inspects thrown exceptions against your `include` / `exclude` list. Non-transient errors (e.g., `400 Bad Request` or `InvalidCardException`) fail fast without retrying.
  3. **Exponential Backoff Engine:** Retries run within non-blocking isolate timers using `(delayMs * (multiplier ^ attempt))`, preserving event loop responsiveness under load.
  4. **State Machine Recovery:** If all attempts fail, control routes to your signature-matched `@Recover` method automatically.

---

### Slide 5: Pro-Tip / Enterprise Best Practice
* **Header:** Production Rule: Combine Retries with Fast-Failing ⚡
* **Best Practices:**
  * **Target Specific Exceptions:** Never retry generic `Exception` types. Only target transient network blips (`SocketException`, `TimeoutException`, `DatabaseConnectionException`).
  * **Add Jitter:** Pass `jitter: true` to `@Retryable` to prevent the "Thundering Herd" problem when dozens of Dart isolates retry remote endpoints at the exact same millisecond.
  * **Observe Metrics:** Track retries on your Actuator dashboard! `jetleaf_actuator` exposes metrics under `retry.attempts.total` and `retry.recoveries.total`.

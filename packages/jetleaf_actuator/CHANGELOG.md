## [1.0.0]

### Added
- Initial release of `jetleaf_actuator` (formerly `jetleaf_monitor`).
- Comprehensive AOT runtime monitoring, actuators, health indicators, and metric collectors.
- Support for structured system diagnostics, JVM/Dart VM memory and process metric reporters.
- Ready-to-use runnable example under `example/`.
- Full integration with `jetleaf_core` 2.0.1 and `jetson` 2.0.1 for high-performance JSON telemetry serialization.
